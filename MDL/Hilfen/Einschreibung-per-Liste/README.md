# Einschreibung per Liste

Hilfsblatt zum Einschreiben vieler Teilnehmender auf einmal über eine Liste mit E-Mail-Adressen (Plugin **local_bulkenrol**), optional direkt in Gruppen.

## Inhalt

- Anwendungsfall: Klausurkurse, Praktika mit Gruppen, Kurswechsel
- Vergleichstabelle: Einschreibung per Liste vs. einzeln vs. Selbsteinschreibung
- Schritt-für-Schritt-Anleitung mit Screenshots (Liste, Vorschau, Ergebnis)
- Aufbau der Liste: Gruppenzeilen (`#`) und Abmelden (`!`)
- Hinweis, wenn der Menüpunkt fehlt
- Links zu Plugin und Moodle-Dokumentation
